Mark16Manager

Your Mark 16 microSD card, neatly organised.

A Windows and Mac companion app for Mark 16 owners. Add games, edit the console menu and keep copies of your saves, using a card reader on your computer. The interface switches between Japanese and English. No Python installation is needed.

What you can do

Prepare your card on your computer, then return it to Mark 16. This app does not play games or connect directly to the console.

01 · Add and organise games

Choose the microSD drive, then drag and drop your ROM files into the game list (or use Add). Files are copied to /MDTANG/ROMS. Supported extensions: .md, .bin, .gen, up to 4 MiB per game.

  • View, rename and remove games on the card.
  • Move games up or down and save the order with numbered filename prefixes.
  • The built-in 555-title database suggests names, genres, publishers and years. Suggestions may need correction.

02 · Edit display names

The ROM filename becomes its name in the console menu. Rename it in the app; related intro and thumbnail files follow the change. Database suggestions help you enter a name.

03 · Japanese & English intros

Edit both languages with a live preview: up to 4 lines, 12 characters per line for Japanese or 16 for English (UTF-8, up to 512 bytes). English wraps at word boundaries, matching v33 / m2-menu11. The app warns when text is too long.

04 · Make thumbnails

Choose or drop an image to convert it to a four-colour .m16 thumbnail. The stored image is 96×28 pixels; the console displays it at 96×56. Preview and save it alongside the intro text.

05 · Back up and restore saves

Copy the card’s .srm files into a dated backup folder on your computer, with SHA-256 checks. Restore a selected backup to the card; existing files are kept as .srm.bak before replacement.

This includes /MDTANG/SAVES/CART_*.srm files saved by cartridge RAM-copy mode, as well as legacy saves beside ROMs. It manages files already on the card—it cannot read or write a physical cartridge’s SRAM.

06 · Prepare firmware files Console update: Coming soon

Place FPGA .fs and Pico .uf2 files in /MDTANG/FPGA. The app records version information inferred from filenames and warns about older versions when it can compare them.

This only prepares files on the card. The console does not yet apply updates from SD. Displayed versions describe files on the card, not a live check of your console.

07 · Export screenshots Console capture: Coming soon

Browse compatible images already in /MDTANG/SHOTS and export them to PNG on your computer, at original size or 2×. The app can read the proposed .m16s format.

The console does not yet save screenshots in this format. This tab is preparation for a future feature; it cannot capture the console screen now.

Beta / in development. Real-card and real-console operation still needs testing. Back up your microSD card before making changes. Save states, EEPROM saves, direct cartridge boot and physical cartridge save transfer are not provided by this app.

Use only game data and images you have the right to use. No ROMs are distributed here.

Getting started

  1. Turn off Mark 16, remove its microSD card and insert it into your computer using a card reader.
  2. Download the ZIP for your computer, extract it completely and open Mark16Manager.
  3. Select the SD drive at the top. Check the drive carefully; do not select your system drive or another storage device.
  4. Add games, edit names, intros and thumbnails, then save your edits. Back up saves if needed.
  5. Close the app and safely eject the card using your operating system.
  6. Put the card back into Mark 16, then turn the console on.

microSD folder layout

/MDTANG/
├── ROMS/    Game ROMs (.md / .bin / .gen)
├── INFO/    Japanese / English intro text
├── THUMBS/  Menu thumbnails (.m16)
├── SAVES/   Save files, including CART_*.srm
├── FPGA/    Update preparation (console support coming soon)
└── SHOTS/   Images (console capture coming soon)

Example intro: INFO/Game.bin.en.txt · Thumbnail: THUMBS/Game.bin.m16. Older saves beside ROMs are also found by the app.

Public release & download files

First launch: unsigned app

Only continue if the file came from this official page. Do not disable your system’s security features.

Windows

Extract the whole ZIP, keep the folder contents together and open Mark16Manager.exe inside the Mark16Manager folder. If SmartScreen shows “Windows protected your PC”, choose More info → Run anyway, if available.

Mac

Extract the ZIP and move Mark16Manager.app to Applications. Right-click it and choose Open, then confirm Open if offered. If blocked, check System Settings → Privacy & Security → Open Anyway.

Fallback, only for this trusted download: open Terminal and run the command below (adjust the path if you placed it elsewhere). It removes quarantine only from this app.

xattr -dr com.apple.quarantine "/Applications/Mark16Manager.app"

Then open the app again. The build is not notarised; prompts differ by OS version.
