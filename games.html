オリジナルゲーム

メガドライブ用のオリジナルゲームです。無料でダウンロードして遊べます。

対応機種　MARK 16 および 一部のメガドライブ※エミュレーター

すべてのエミュレーターでの動作を保証するものではありません。

ザ・ビルディング

THE BUILDING　／　メガドライブ用ソフト（遊べる試作）

ダウンロード

災害（地震と火事）に襲われた高層ビルで、会社員の主人公が2階から屋上まで登り、ヘリコプターで救出されるまでを遊びます。導入では、1階のロビーからエレベーターに乗り、2階に着いた直後に1階で大爆発が起きます（導入は START で飛ばせます）。

操作

十字キー 左右歩く（だんだん速くなり、離すと少し滑って止まる）
A / B / Cジャンプ（長く押すほど高く跳ぶ。はしごにつかまっている間は飛び降り）
十字キー 上・下はしご・ロープを登る・降りる。空中で上を押していると、ふちにつかまる
十字キー 下傾いた床で踏ん張る（すべり落ちない）
ぶら下がり中上または前でよじ登る（下かボタンで手を離す）
ロープ中の A/B/C手を離す（左右を押しながらなら、その向きへ跳び移る）
STARTタイトルから導入へ。導入中にもう一度押すと飛ばして、2階のプレイ開始

内容

  • ステージは7つ（各4フロア、2階〜28階）と屋上です。上へ行くはしごを探して登ります。
  • 残機は3。ミスすると、そのステージの最初からやり直しです。
  • 迫りくる火事、炎、落下、ガス爆発、暴風、傾いた床、天井の破片などがあります。
  • 絵と音楽、効果音はすべてオリジナルです。
  • スコア・タイム・セーブ・ポーズは、まだありません。

MARK 16 での遊び方

  1. microSDカードのルートに MARK16 フォルダーを用意します（古い MDTANG フォルダーではありません）。
  2. ZIPを解凍し、the_building.bin を MARK16/ROMS へコピーします。
  3. カードを本体に入れ、ゲーム一覧から選んで遊びます。整理には PCアプリ「Mark16Manager」 も使えます。

ザ・ビルディングをダウンロード

無料で遊べます。販売目的での再配布はご遠慮ください。ZIPにはROMと、操作・対応機種を書いた短い説明（日本語／英語）が入っています。

シンプルドラム

SIMPLE DRUM　／　メガドライブ用ソフト

ダウンロード

画面中央のドラムセットを、パッドの各ボタンで叩くだけのシンプルなドラムです。フリー演奏のほか、オリジナル3曲に合わせて叩けるセッションと、ボタンのわりあてを変えるオプションがあります。

操作

タイトルは「フリー／セッション／オプション」のメニューです。上下で選び、A／C／START で決定。プレイ中の START でタイトルに戻ります。MODE は使いません。

Aバスドラム（キック）
Bスネア
Cフロアトム
Xハイトム
Yミッドトム
Zリム／クラップ
上クラッシュシンバル
下オープン・ハイハット
左クローズド・ハイハット
右ライドシンバル

上の表は既定のわりあてです。オプションでパッド種別（AUTO／6ボタン／3ボタン）、かさねおと（オフ／オン、既定はオフ）、各入力の音色わりあてを変えられます。3ボタンパッドだけでもメニューは操作できます。設定は電源を切ると元に戻ります。

セッション

  • 1・ロック 8ビート（既定 130 BPM）
  • 2・ハード シャッフル（既定 156 BPM）
  • 3・スロー ブルース（既定 84 BPM）

左右でテンポを調整してスタートすると、4拍のカウントインのあと、リードギターとベース、パワーコードに合わせてドラムを自由に叩けます。右側にギタリスト、左上に拍とグルーヴメーターが出ます（失敗の判定はありません）。ドラムの音はすべて自作の合成音です。

MARK 16 での遊び方

  1. microSDカードのルートに MARK16 フォルダーを用意します（古い MDTANG フォルダーではありません）。
  2. ZIPを解凍し、simple_drum.bin を MARK16/ROMS へコピーします。
  3. カードを本体に入れ、ゲーム一覧から選んで遊びます。整理には PCアプリ「Mark16Manager」 も使えます。

シンプルドラムをダウンロード
